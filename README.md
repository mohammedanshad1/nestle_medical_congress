# Nestlé Medical Congress 2026

A modern, responsive Flutter mobile and tablet application for the Nestlé Medical Congress (Vienna • May 22–23, 2026).

## Features

- **Event Dashboard**: Featured symposiums, upcoming sessions, and congress highlights.
- **Scientific Agenda**: Multi-day session schedules and track details.
- **Speakers Directory**: Keynote speakers, research topics, and faculty profiles.
- **Digital Name Tag**: Secure attendee badge with QR code entry pass.
- **Interactive Venue Map**: Conference hall maps, booth directions, and navigation.
- **Live Q&A & Voting**: Real-time audience polling and session questioning.
- **Resource Center**: Download scientific slide decks and medical papers.
- **Attendee Profile**: Personal credentials, CME credits, and certificates.

## Tech Stack

- **Framework**: Flutter (Dart)
- **Design**: Dark Royal Navy & Cyan Glassmorphism UI
- **Responsive**: Supports mobile & tablet screen sizes
- **Fonts**: Google Fonts (Plus Jakarta Sans)

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/nestle_medical_congress.git
   cd nestle_medical_congress
   ```

2. **Install dependencies:**
   ```bash
   flutter pub get
   ```

3. **Run the app:**
   ```bash
   flutter run
   ```

4. **Run tests:**
   ```bash
   flutter test
   ```
